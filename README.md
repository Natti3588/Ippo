# Ippo

Go言語の標準ライブラリと Next.js で作成した英語学習を啓発させるための Webアプリです。

## 開発の背景

母の「いつかは英語を話してみたい」という言葉をきっかけに、英語学習への一歩を後押しするWebアプリ「Ippo」を開発しました。
開発では、サービスを形にするだけでなく、自分自身の技術理解を深めることも目的としました。
バックエンドとフロントエンド間で生じる型のズレを防ぎ、APIファーストな開発への理解を深めるために TypeSpec を採用しました。
バックエンドには Go を採用し、フレームワークに頼らず標準ライブラリを中心に実装することで、HTTPサーバーの仕組みや並行処理など、Goの基礎への理解を深めました。
フロントエンドには Next.js を使用し、SSRを含むレンダリングの仕組みについて学びました。
また、インフラは Terraform を用いて AWS 上に構築し、各AWSサービスの役割や、それらがどのように連携してWebアプリケーションを構成しているのかを、実際に構築しながら理解することを目指しました。
